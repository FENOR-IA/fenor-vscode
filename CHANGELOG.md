# Changelog

## 0.1.0 — 2026-10-05

Primeira versão.

- **Portfólio:** detecta projetos Java, React, PHP (Symfony, Laravel, apps Fenor), Node e Python; situação de cada um (git + `.md`), pendências e relatório.
- **Azure DevOps:** sprint atual, alertas, carga do time, commits ligados a work items (`AB#123`).
- **IA trocável:** os mesmos comandos com GitHub Copilot, Claude Code ou Codex; `@fenor` no chat do Copilot.
- **Kit Fenor:** memória estruturada, modos (planejar, executar, revisar, corrigir defeito, nova feature, salvar sessão), regras por stack e agentes/skills do ECC, nos formatos das três IAs.
- **Copilot no nível do método:** ferramentas `#fenor_contexto`, `#fenor_verificar` e `#fenor_salvar_sessao`; instruções por projeto aplicadas pelo caminho.
- **Sistemas e vault:** painel para agrupar projetos (front, back, API…) e gerar um vault estilo Obsidian como repositório próprio.
